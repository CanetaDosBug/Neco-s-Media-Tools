Neco's MediaTools

Programa desktop pra baixar áudio/vídeo de links (YouTube, TikTok, Instagram, etc.) e converter arquivos entre formatos comuns (imagem, documento, planilha, áudio, vídeo).


O que dá pra fazer

- Colar um link e baixar em MP3, MP4, WAV e outros formatos
- Converter vários arquivos de uma vez (imagem, docx, xlsx, mp3, mp4, etc.)
- Tema claro/escuro

Como baixar

Baixe o .zip do drive -> https://drive.google.com/file/d/1YnaADGXI-4a9BjLeLf_-V4hrl-pVHyUI/view?usp=sharing
Extraia e execute o NecoMediaTools.exe
