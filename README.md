Neco's MediaTools

Programa desktop pra baixar áudio/vídeo de links (YouTube, TikTok, Instagram, etc.) e converter arquivos entre formatos comuns (imagem, documento, planilha, áudio, vídeo).

O que o aplicativo faz

- Lê um link de mídia comum e baixa em MP3, MP4, WAV e outros formatos
- Converte vários arquivos de uma vez (imagem, docx, xlsx, mp3, mp4, etc.)

Como baixar

1. Baixe o .zip em releases -> https://github.com/CanetaDosBug/Neco-s-Media-Tools/releases/tag/1.0
2. Extraia e execute o NecoMediaTools (executável)

Pacotes recomendados:

- Para baixar os vídeos e músicas (já vem embutido):
https://ffmpeg.org/download.html 

- Para conversão de tipos mais específicos de arquivo:  
https://www.libreoffice.org/download/ - Para vários tipos de documentos
https://calibre-ebook.com/download - Para ebooks

Aviso

Feito pra uso pessoal. Respeite os termos de uso dos sites de onde for baixar conteúdo.
